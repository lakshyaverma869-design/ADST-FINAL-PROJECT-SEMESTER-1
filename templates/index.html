Data Science and Machine Learning project

Dynamic EV Charging Forecasting

An ML-based system that estimates EV charging demand using traffic indicators, weather, time and city-level information.

Important: The model estimates charging sessions. This project does not measure actual charging demand; training labels are synthetic.

↗

Three ways to explore

Use current weather for a live estimate, historical weather for analysis, or available forecast weather for a future estimate.

Traffic and EV count are only used when supported by an explicitly identified source.

Mode 1

Live Prediction

Select a city. Current weather is retrieved automatically; optional live road-flow status is reported when a TomTom key is configured.

Open Live Prediction

Mode 2

Historical Analysis

Choose a city and date range. Open-Meteo historical weather is combined with clearly labelled model estimates.

Open Historical Analysis

Mode 3

Future Forecast

Choose a future city-hour. Forecast weather is used when available; longer dates use a labelled historical weather analogue.

Open Future Forecast
